# Gravitas

Roblox semi-idle, single-character hack-and-slash RPG. This repository currently houses the collaborative design notebook, not implemented gameplay.

## Design navigation
- [Master design tree](docs/design/MASTER-TREE.md): all 24 branches and their nested exploration topics.
- [Current direction and decision ledger](docs/design/DIRECTION.md): established decisions, references, proposals and open questions.
- [Character and class progression](docs/design/PROGRESSION.md): approved shared character growth, class mastery, promotions, mastery catch-up and optional complexity.
- [Skills and collection](docs/design/SKILLS-AND-COLLECTION.md): Energy, skills, summons, Stardust, pets, mounts and monetization.
- [World and idle progression](docs/design/WORLD-AND-IDLE.md): party limits, map dungeons, shared progress and idle rewards.
- [Elements and reactions](docs/design/ELEMENTS.md): ten-element proposal, reaction matrix, cosmic modifiers, VFX and progression additions.
- [Shared combat and equipment foundations](docs/design/COMBAT-FOUNDATIONS.md): roles, specialties, status effects, attributes and equipment exploration.
- [Weapon roster and compatibility](docs/design/WEAPONS.md): planned full-game weapons and proposed starting class pairings.
- [Class architecture and reusable template](docs/design/CLASSES.md): foundational classes, advancement candidates and future hybrid/special classes.
- [Combat switching proposal](docs/design/COMBAT-SWITCHING.md): possible class/weapon switching, independent cooldowns, extended combos and progression.
- [Discussion workflow](docs/design/WORKFLOW.md): how to maintain and expand the tree.

Status labels: **Established** = explicitly decided by the owner; **Exploratory** = candidate, not canon; **Future** = intended later; **Undecided** = unresolved. Do not equate a listed feature with a commitment or launch scope.

Repository name is used as the project label; final public-facing game title is not established.
