# Warrior lineage talent tree

Status: assistant proposal for owner review, not approved numerical tuning. Canonical shared rules and point economy: [TALENTS](../TALENTS.md); established architecture: [CLASSES](../CLASSES.md), [PROGRESSION](../PROGRESSION.md). Class-exclusive Trait/skills remain in [foundation kit](../classes/WARRIOR.md). All effects are intended as modest linear per-effective-rank increments. No node unlocks an ordinary skill or introduces an attribute. Explicitly tagged compatible skills only; no automatic change to all attacks from equipping a lineage.

Durable frontline combat, physical weapons, break and responses to pressure. Fortitude is not exclusive to shields; offensive paths remain useful for Berserker and mixed classes.

## Expansion direction (not yet designed)
P II: sustained pressure, interception, counterattack and formation support. P III: broader frontline mastery and alternate defensive/offensive investments. Reserve deep transforms for promotion-kit review; no new mandatory armor gauge.

## Verification and dependencies
24 nodes, 100 native investment ranks, 50 per section. First two nodes in a branch proposed open on section access, third/fourth gated by invested branch ranks (5/10; review). All magnitudes, exact conditions, units, event flags and effect caps TBD. At effective ranks above normal investment caps, preserve linear magnitude until explicit safety cap. Do not count bonus effective ranks toward paid prerequisites. Transformative nodes modify a measurable existing component per rank rather than unlocking entire extra actions at rank one. Direct hits, proc hits, status duration, skill geometry, target caps and resource loops require review against existing combat rules. Later sections deferred until their class kits exist.
