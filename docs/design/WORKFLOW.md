# Design notebook workflow

- Start with [current direction](DIRECTION.md) and the [master tree](MASTER-TREE.md). The master tree is a stable index, not a commitment or release schedule.
- Keep one canonical system document per subject. When a decision changes, edit its current rule in place, update affected cross-references, and remove obsolete alternatives or examples that no longer help. Git history retains previous versions; do not append chronological correction logs to active specifications.
- Distinguish Established (owner-confirmed), Proposed (under review), Future (deferred), and Open (not yet decided). Never silently promote assistant examples into canon.
- Preserve meaningful unresolved alternatives and implementation questions, but avoid repetitive recaps, speculative filler and redundant copies of specifications.
- Keep this project separate from ORBIT!, OMDB and other Roblox concepts. Do not import their mechanics without approval.
- Maintain concise README navigation and stable branch IDs. Validate links, current terminology and contradictions after changes.
- Optional depth is a game-wide requirement; ordinary play should not require detailed mechanical knowledge.
- Current priority: resolve XP attribution across permanent account-wide Character Level, independent lineage levels and individual Class Mastery; same-lineage talent node overlap (lineage prestige scope confirmed; working caps 60/80/100; all earned progression retained, catch-up accelerates lagging lineages), then weapon switching/skill inheritance and remaining ordinary roster choices; begin individual foundation kits with Warrior. One talent point per lineage level gained after tree unlock is the only source; each lineage owns its cumulative points. See PROGRESSION.md for XP attribution, account-level reward/penalty/scaling formulas, and future system unlock map. Most foundational major systems unlock in Prestige 0; mounts very early Prestige I; later prestige/stage clears can unlock major systems. One persistent character per account at launch. Initial scope: two promotions per foundation and ten core-pair hybrids (25 ordinary/core-hybrid classes), plus Sword Saint, Summoner and Gunslinger special families with simpler horizontal variants; variant names/counts and release scope open. Samurai is the Warrior + Ranger hybrid. Review Ranger's second promotion replacement and remaining ordinary roster choices; special families and their variants are deferred by owner, preserve concepts without designing kits, progression or acquisition for now. Not a launch commitment. Primary/secondary inherent class growth, talent and weapon scaling direction, passive/trait scope and linear talent rank overflow established; starting multipliers approved (50% secondary class growth/talents/weapons, 150% specialized class growth/talents, no overlapping-growth penalty); exact talent rank interaction rules open. Five shared lineage talent trees and three node categories approved; tree unlock level, hybrid access and specific nodes remain open. Impulse and simple preset/custom macro direction established. Economy concept established with Gold, Orbs, Stardust, summon tickets and reusable resource families; rates and prices deferred. Attributes, slots, status/idle refinements and itemization have been explored and should not be repeated. Numerical balance, Reforge, relics and full manual combat are later work.
- No gameplay implementation is represented by this design notebook.
