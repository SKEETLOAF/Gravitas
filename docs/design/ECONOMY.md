# Economy and currencies
Updated 2026-11-26. Core currency names and compact resource direction approved; exact prices and rates open.

## Core wallet
| Currency | Purpose |
| --- | --- |
| Gold | Ordinary upgrades, crafting, purchases and ascension costs |
| Orbs | Premium currency for summons, cosmetics and conveniences |
| Stardust | Exchange currency from disassembling unwanted summons, including before max rank |
Orbs earnable through gameplay as well as purchasable (recommended). Paid acceleration allowed; free players must have realistically attainable equivalent power and guaranteed acquisition routes.

## Tickets and materials
Earnable Skill, Pet, Mount and Cosmetic Summon Tickets. Event-specific tickets/currencies may exist where useful, not for every event. Orbs as summon alternative recommended; exact costs and pool eligibility open.
Keep resource families general and reusable rather than creating a separate material for each class, region, item or tier.
| Resource family | Purpose |
| --- | --- |
| Skill XP | Ordinary skill development |
| Pet XP | Ordinary pet development |
| Ascension items | Class Trait upgrades, pet generation advancement and other compatible ascension uses if designed |
| Shards | Star-rank upgrades alongside duplicates |
| Reforge material | Future attribute/value rerolls |
| Equipment enhancement material | Candidate shared resource for slot enhancement/crafting |
Mount upgrades use existing shared resources where practical; exact XP or material assignment open. Universal versus category-specific shard eligibility, duplicate-to-shard conversion and material naming remain open. Harder upgrades primarily require greater quantities or a rarer grade of the same resource family. Add a distinct family only for a meaningful mechanical purpose. Do not introduce separate regional/dungeon currencies by default.

## Sources and sinks
- Online adventure: Gold, XP, equipment and relevant materials. Offline: reduced XP/Gold/eligible materials, 24-hour cap, no equipment.
- Dungeon mobs and bosses: equipment and useful shared materials; targeted set acquisition through earned rewards/crafting is a candidate. Boss-only 10-minute respawn, optional Robux skip; earned skip tokens recommended.
- First clears, promotions, quests, events and recurring activities: tickets, Orbs and shared resources as appropriate.
- Salvage unwanted equipment for reusable resources; disassemble eligible unwanted summons for Stardust. Stardust exchange offers selected rewards, shards or selectors as appropriate; exact catalog open.
- Normal upgrades should not require premium currency. Preserve slot enhancement investment, pet ascension donor mechanics, and ordinary skill/companion development. See [Itemization](ITEMIZATION.md) and [Skills](SKILLS-AND-COLLECTION.md).

## Economy guardrails
Transparent odds and costs, multiple pity levels and guaranteed acquisition alternatives; no automatic premium spending. Free players can attain equivalent power; small cosmetic ownership bonuses should be attainable without paying. Paid random rewards require applicable Roblox disclosure/eligibility checks; validate current policy before implementation. Trading, gifting, marketplace and item restrictions remain open for multiplayer design. No exact costs, grades, earning rates, pity thresholds, prices or economy simulation approved.
