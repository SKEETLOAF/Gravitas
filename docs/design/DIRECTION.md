# Current direction
Updated 2026-11-26. This is a concise overview; linked system documents are canonical.

## Identity and guardrails
- Roblox semi-idle, real-time hack-and-slash RPG with one persistent customizable character and learnable/equippable classes, not a hero roster.
- AFK Dungeon-like moving battlefield combat; optional active input and future full manual combat. Hybrid worlds/instances, co-op and guilds.
- Optional depth: casual players including children can use sensible builds and enjoy progression without mastering underlying RPG rules. Advanced optimization is available, not compulsory.
- Paid acceleration is allowed, but free players have realistically attainable equivalent power and guaranteed acquisition paths. No mandatory purchase to progress.
- [References](REFERENCES.md) includes Torchlight: Infinite and Black Desert Mobile as ARPG inspirations.

## Current system decisions
| System | Direction | Canonical document |
| --- | --- | --- |
| Classes | Expand rather than replace disciplines; retained mastery, one inherent passive trait per class (mastery/Ascension items), hybrid/special options. Five foundations with two promotions each (15 ordinary classes) plus one hybrid per unordered core pair (10 hybrids, 25 in ordinary/core-hybrid design scope), plus shorter special families with horizontal variants (Sword Saint (anime/manhwa swordsmanship), Summoner, Gunslinger), competitive universal scaling; plus a unique jack-of-all-trades class concept (all-C growth, any unlocked skill); promotion topology and named roster proposed; five shared base talent trees approved with Attribute, Conditional and Transformative nodes (3–5 ranks each; modest linear cumulative effects, effective rank overflow); primary 100%/secondary 50% class growth and talent ranks (minimum one per invested secondary talent node), 150% primary growth/talents when specializing, no growth-affinity overlap penalty; separate skill acquisition; one talent point per level gained after tree unlock (only source); prestige scope, point ownership and hybrid access open. | [Classes](CLASSES.md) |
| Weapons | 11 families / 13 categories including firearm weights; class-linked primary and secondary types; equipped primary weapon 100% stats, secondary 50% stats. | [Weapons](WEAPONS.md) |
| Switching | Two class selections, two shared weapons (one skill each), shared equipment/companions; 0.5s class swap cooldown; duplicate-class specialization scaling and both passives; class-associated passive eligibility, active-class Trait; saved class talent loadouts with slot-based contributions. Auto mixes basic strings, Impulse extensions (including support skills), and class swaps with pursuit via simple developer presets and player-created macros; Armor prevents stagger/knockback until broken. | [Switching](COMBAT-SWITCHING.md) |
| Combat | 29-attribute roster, Energy, stat-based defenses; Crit/Super Crit and Block/Super Block; no Ultra Crit currently. Enemy Armor and Break; player breakable Armor not planned by default. | [Combat](COMBAT-FOUNDATIONS.md) |
| Elements | Ten-element working roster; primer-first when required; cosmic stacking any order; reaction consumption/transformation; no general reaction cooldown; control diminishing returns. | [Elements](ELEMENTS.md) |
| Progression | Character level with 18-point class-specific main-attribute growth (F–S grades; S costs seven budget points for six growth weight), modest soft-attribute growth (20 proficient or 5 non-proficient reference units against 75 external; targets not caps), independent class mastery, catch-up, Class Change/Prestige resets only stage level to 1 with working caps 60/80/100, all earned progression retained, reset scope open, retained earlier disciplines. | [Progression](PROGRESSION.md) |
| Skills/companions | Four actives, one ultimate, one of two passives per class (both when specializing); base kits, alternate skill summons, star ranks, pity, Stardust disassembly; pets/mounts available from start; pet generations and potential ascension. | [Skills and collection](SKILLS-AND-COLLECTION.md) |
| Gear/cosmetics | Slot primary, unrestricted smaller secondary rolls, accessories unrestricted; seven rarities with 0–6 secondary lines; dark-purple Secret; separate cosmetics with minor benefits. | [Itemization](ITEMIZATION.md) |
| Adventure | Same-location party progress; 4-person worlds, 6/8-person raids, server/global bosses; map-ending dungeon, boss-only 10-minute respawn. Reduced offline rewards up to 24 hours, no equipment. | [World and idle](WORLD-AND-IDLE.md) |

## Open and deferred
Current priority: class architecture and actual class kits; economy concept established, detailed tuning open. Core foundations and itemization are conceptually covered; do not reopen them without a design need. Numerical formulas, temporary buff/debuff caps, precise promotion/loot/summon rules, detailed swap execution and specific skill kits remain open. Relics, Reforge, full manual combat and detailed choreography deferred. World setting, final title, individual content, presentation and release scope still to design. See [master tree](MASTER-TREE.md).
