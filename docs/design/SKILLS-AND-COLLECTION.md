# Skills and companions
Updated 2026-11-26. Conceptual decisions and open details.

Prestige labels in this document describe intended progression ranges/release windows; shared system access uses Character Level and usually adventure-stage clears, not a mandatory lineage prestige. See PROGRESSION.md. Individual skill, pet evolution and upgrade requirements remain separate.

## Skills
Each class offers 2 Core Skills (basic attack choices), 4 Normal, 4 Rare and 4 Legendary active skills, and 5 passive skills. Each lineage additionally offers 4 shared starter Normal actives and 5 shared starter passive skills. Each class loadout equips 1 Core and 3 ordinary actives; proposed 5 passive-skill slots per class loadout, separate from the existing inherent Trait and two selectable class passives (one equipped per distinct class, both for specialization). Ultimates are deferred, not equipped now. Owner confirms max-star skill upgrades can tier up; exact star cap, tier ladder, costs and carryover open.
Functional base kit at acquisition; alternate skills through summons. Compatible learned ancestral ordinary skills inherit transitively on promotion and from hybrid parents, not reverse; class-exclusive Traits and selectable class passives do not inherit. New passive-skill inheritance and Core Skill eligibility require confirmation; recommend compatible lineage/ancestral passive skills and class-specific Core choices. Core Skills define basic attack behavior using universal weapon-family animations; exact weapon compatibility and animation reuse open. Ordinary active skills use shared Energy; recommend free Core attacks; passive skills trigger according to their conditions. Cooldowns persist through swaps. Same-class specialization provides two 1-Core/3-active loadouts and both existing selectable class passives, one Trait; no cooldown reduction bonus. Proposed passive-skill slots per loadout, active/passive trigger scope and duplicate stacking to review; identical skill IDs sharing cooldowns recommended. Weapon skills remain separate. Mastery does not award ordinary class skills. Skill XP for levels; duplicates/shards for stars; max-star upgrade can advance tier (owner-confirmed). Recommend retaining learned skill identity and investment, with tier enhancements; whether tiers map directly to rarity, star counts, cap beyond Legendary and exact costs open. Awakened skills P III remain planned; relationship to tier advancement open. Inspiration: Go Go Muffin Core/Tactical/Passive and star investment (https://boarhat.gg/games/go-go-muffin/guide/beginner-guide/); Sword x Staff slot-level upgrades (https://www.prydwen.gg/sword-x-staff/guides/tips-and-tricks) are an optional investment-protection alternative, not approved. Normal skills should retain situational value rather than be strictly obsolete (recommendation).

## Summons and Stardust
Selectable summon focus, multiple pity levels, guaranteed acquisition alternatives. Recommend standard/class-focus/wishlist/featured pools, soft pity, hard rarity guarantee, target guarantee, compatible-banner pity carryover. Unwanted eligible summons may be disassembled into Stardust at any rank, and duplicates beyond all available star/tier progression may convert; max-star duplicates may instead fund tier advancement. Stardust redeems selected rewards, potentially star-rank shards/selectors. Protect locked/favorite items, clear costs/outcomes, spare-copy handling without removing learned skills recommended. Exact odds, exchanges, cross-pool eligibility and rank caps open.

## Pets
Available from start. Visible mini partners, own basic attacks and customizable equippable pet moves inspired by Go Go Muffin, replacing the single fixed-skill model (owner-confirmed). Pet moves unlock during Prestige 0. Exact move slots, acquisition, compatibility, active/passive behavior, upgrade and rarity rules open. Evolved pets gain access to Mythic Moves during Prestige II (owner direction); evolution and move upgrade requirements open. Cool appearances, rarities, degrees of aid, Pet XP development, summons and duplicate/star-rank upgrades. New generations/variants unlocked by Character Level and appropriate stage requirements; exact gates open. Earlier pets can become obsolete naturally.
Proposed Pet Ascension (tentative Prestige II unlock): consume eligible newer-generation donor plus Gold/ascension items to raise a favorite pet's generation/scaling ceiling. Deterministic, retain identity and existing attacks/move investment; no automatic donor move inheritance. Preview, lock protection and explicit confirmation recommended. Exact donor requirements, rank conversion, costs, generation count and thresholds open.
Recommended one equipped pet; generation, rarity and star rank separate. New generation access permanently character-wide once requirements met recommended; Class Change stage resets do not revoke earned access (owner-confirmed). Exact Character Level and adventure-stage milestone mapping open (PROGRESSION.md).

## Expeditions
Owner accepts companion expeditions as a system. Candidate: dispatch unused pets for resource rewards without interrupting active combat. Exact participating companions, rewards, durations, slots, unlock timing and rules remain open.

## Mounts
Paced for very early Prestige I (actual Character Level/stage unlock thresholds open, see PROGRESSION.md), general-purpose across classes, one usable skill, modest player enhancement, rarity and duplicate upgrades, cool appearance. Not an independent fighter; no mandatory pet-like generation ladder. Recommend one equipped mount. Mount equipment unlocks at Prestige III (owner-confirmed). Equipment slots, stats, acquisition and upgrades remain open. Skill activation while mounted/unmounted, slots, travel, bonus ranges and acquisition details open.

## Monetization and deferred systems
Paid acceleration with realistically attainable free equivalents, transparent odds/costs, guaranteed acquisition, no mandatory purchase gates, investment protection. See [Economy](ECONOMY.md). Paid random rewards require applicable Roblox eligibility and disclosure; verify rules before implementation. Relics are powerful unique build-synergy upgrades introduced at Prestige II; detailed design deferred. Stellar Path-like progression is a distant Prestige III+ concept. Exploratory proposal only: Authority (owner-selected system name), suggested Prestige IV+, a class-independent Manifestation ability modified by Astral Sigils and developed through a Constellation progression layer. Illustrative powers Singularity, Supernova, Event Horizon, Genesis and Paradox. System name approved; mechanics, extra gear/skill slots, acquisition and exact unlock remain unapproved; preserve Energy and class combat identity when designing.
