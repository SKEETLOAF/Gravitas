# Character and class progression
Updated 2026-11-26. Overall model approved.

## Three layers
1. Character Level: global XP from combat, quests, stages, dungeons and eligible idle rewards; general power, equipment eligibility and system milestones. Class Change/Prestige stage levels are independent per lineage and serve class evolution unlocks; see below. The existing global Character Level concept remains separate pending reconciliation of XP tracks. Ordinary class swapping does not reset progression. Owner establishes inherent class-specific base attribute scaling with Character Level, distinct from Class Mastery, gear, talents and Class Traits. Each class uses an equal 18-point main-attribute growth budget across Health, Energy, ATK, MATK, DEF and Magical Defense. Growth weights display as F=1, D=2, C=3, B=4, A=5, S=6. Ordinary focus caps at A; S is reserved for exceptional focus at an additional trade-off. Approved S-grade trade-off: each S costs 7 budget points for weight 6 (one-point surcharge, so raw weights sum to 17 for one S). Growth weights are not fixed stat values. Soft attributes grow modestly through Character Level; proficient attributes have roughly comparable natural growth across classes, while non-proficient attributes grow much more slowly. Approved approximate soft-attribute growth reference weights: 20 proficient or 5 non-proficient natural growth units against 75 external progression units at a comparable benchmark. The two natural rates are alternatives, not additive. Weights are not literal realized percentages or hard caps. Equipment and talents lead external growth, pets/mounts supplement, cosmetics are modest, and relics may be build-defining later. Actual normalization and curves remain for numerical balancing. Exact natural growth rates remain open; foundational proficiency profiles in CLASSES.md. Use data-driven profiles; equal weights alone do not guarantee equal combat value. Ordinary class swapping never resets progression; exact relationship between global level and lineage evolution-level growth remains open. Owner approves primary 100% plus distinct secondary 50% inherent class growth, or 150% of a single profile when specializing. Do not reduce growth contributions for overlapping grades or affinities. Talent ranks use the same multipliers; weapon attributes remain 100% primary and 50% secondary. Apply to class-derived growth, independent of active class; do not duplicate shared base stats or multiply shared external bonuses. Exact curves and deeper stat allocation remain open.
2. Class Mastery: independent progression for every learned discipline, retained permanently. Ordinary skills, talents, inherent Class Trait unlock/upgrade milestones and promotion eligibility. Each class has one passive trait leveled through Class Mastery requirements and shared Ascension items; thresholds, costs and level caps open. Recommended designated training class receives full class XP, other participating classes smaller share; exact distribution open. New class gets functional base kit and retains general character progression. Catch-up approved: underdeveloped classes/lineages advance faster toward the player's developed progression, including their evolution levels; benchmark, XP attribution and taper formula open. Catch-up accelerates earning levels, not automatic prestige unlocks.
3. Promotions: mastery threshold, relevant adventure milestone (already attained counts), promotion trial achievable via ordinary auto-combat. Unlock distinct independently usable discipline, retain earlier classes. Catch-up accelerates mastery but does not skip requirements. Initial scope two promotions per foundation (15 ordinary classes including foundations); Each lineage independently reaches its stage cap to qualify for the next Class Change, which resets only that lineage's stage level to 1 and raises its cap. Exact additional unlock requirements and topology remain open. Shared lineage eligibility recommended; exact unlock topology, names, levels/caps open. Hybrid unlocks can differ. Special families (Sword Saint, Summoner, Gunslinger) use shorter, simpler variant-based advancement instead of long mandatory promotion ladders, retaining competitive scaling through universal progression. Exact family mastery, variant unlock requirements, talent access and kit ownership open; see CLASSES.md.

## Class Change / Prestige (owner direction)
Class evolution uses Class Change/Prestige stages, each beginning at displayed level 1 with a higher maximum level. Working caps: foundation 60, Class Change I 80, Class Change II 100, then approximately +20 per future stage. Exact caps/XP curves are tuning decisions. This supersedes the earlier no-prestige recommendation. Ordinary combat/loadout swapping is not a Class Change and never resets a level. Earlier disciplines remain accessible.
Owner confirms independent lineage advancement: the stage level tracks eligibility for the next prestige in that respective class lineage. Prestiging one lineage does not advance or reset any other lineage. Underdeveloped lineages benefit substantially from catch-up, but must earn their own levels and qualify for their own Class Changes. All accumulated inherent attribute growth, earned talent points, equipment and eligibility, skills, mastery, pet-generation access, adventure progress and previously unlocked content are retained; only that lineage's displayed stage level resets. Track cumulative progression separately from the displayed stage level. Existing promotion trial/adventure/mastery requirements remain working proposals to reconcile against level caps. Exact relation of evolution-stage XP to Class Mastery and any separate global Character Level remains open; recommend avoiding an additional redundant XP grind. Talent points are earned and owned independently by each lineage (owner-confirmed); exact growth attribution across independent lineages remains open.

## Supporting progression
Skill level and star ranks separate from mastery; gear, pet and mount tracks distinct. Pets and mounts available from start. Pet generations through class progression and high character level; mounts universal. Up to two class selections and two shared weapons, with slot unlock milestones open. Saved talent loadouts supported; one reusable tree per foundational lineage approved; Owner-approved source: earn exactly one talent point per level gained after the talent tree unlocks; no other point-award source. Each lineage earns and owns its own cumulative talent points through its level progression (owner-confirmed); no transfer or universal pool. Recommend reusable allocations for descendants sharing that tree. Unlock level and treatment of the unlock-level gain remain open. Earned points are retained across Class Changes (owner-confirmed); recommend reusing the applicable capacity per saved allocation, never award a point merely for resetting to level 1; prevent repeat grants for the same earned level milestone. External bonus effective ranks remain distinct from earned talent points. Mastery/promotion milestones may unlock deeper lineage nodes; exact gates open. No separate talent XP track. Attribute, Conditional and Transformative nodes have 3–5 upgradeable ranks each with modest individual effects designed for cumulative investment in expanding trees, and modify existing attributes/mechanics/skills, not ordinary skill acquisition. Primary allocation contributes 100% ranks, secondary 50% with fractional effective ranks and minimum one for invested nodes; same-class specialization contributes 150% primary ranks. Linear rank increments support effective ranks beyond investment caps via external bonuses. Point costs, prerequisite rules, multipliers and rank rounding/order open. See CLASSES.md. Selecting the same class twice provides specialization scaling instead of a second skill kit; potential cooldown reduction and values open. Class Change stage resets follow the rules above. See [Skills](SKILLS-AND-COLLECTION.md), [Itemization](ITEMIZATION.md), [Classes](CLASSES.md).

## Accessibility
Simple default view of current character/class, next promotion, recommended upgrade and adventure goal. Optional advanced stats and build analysis. Explainable reversible recommendations, no automatic premium spend or destruction of locked items. Avoid redundant XP tracks. Detailed UX later.
