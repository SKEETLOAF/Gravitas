# Character and class progression
2026-11-26 | Proposed model for owner review, not approved.

## Established accessibility principle
The owner wants a cool, approachable experience for children and casual players, with optional depth for dedicated optimizers. Players need not understand all underlying systems to progress. Detailed onboarding and UX design deferred until systems are established. Favor automatic/default sensible choices, progressive disclosure, plain descriptions and recommendations; advanced build analysis is optional. Do not equate optional complexity with removing mechanical depth.

## Proposed three progression layers
1. Character Level (global XP): one permanent level for the character from combat, quests, stage clears, dungeons and eligible idle rewards. Represents general power, equipment eligibility and account/character system milestones. No reset on class switch. Automatic baseline attribute growth; optional deeper customization to be decided. Avoid hard-locking every stage behind level; dungeon completion remains main map gate.
2. Class Mastery (class XP): independent progression for each unlocked playable discipline, retained forever. Earn alongside Character XP by fighting, completing activities and eligible offline training. Class mastery unlocks ordinary skills/talents/benefits as appropriate and contributes to promotion eligibility. Proposed distribution: a designated training class receives full class XP; other equipped classes receive a smaller share if participating; alternatively split according to combat use. Do not require manual swaps or last hits to earn mastery, including supports. Exact shares undecided. New class starts with functional kit and inherits character level, equipment compatibility and general progression. Catch-up bonus for underdeveloped classes based on highest mastered class or character progress, without instantly granting promotion.
3. Promotions (milestones): climb each of the five proposed core lineages through earned mastery thresholds plus appropriate campaign milestones or short promotion trials. Promotions unlock distinct selectable combat styles/disciplines without replacing earlier ones, consistent with confirmed class expansion. Suggest a shared lineage eligibility record to avoid restarting a whole grind at each unlock; each individual promoted class still has mastery and distinct benefit. Special/hybrid classes unlock through specific accomplishments and possibly multi-class prerequisites, not necessarily a core lineage. Exact architecture (linear vs branches), names, level caps, promotion count, unlock requirements and inheritance still open.

## Supporting progression
Skill levels and star ranks remain separate from class mastery and use earned materials/duplicates. Gear, pets, mounts have own improvement tracks as already discussed. Avoid additional redundant weapon/account/ascension XP tracks unless a clear purpose is established. Character-wide progression unlocks additional class/weapon swap slots at milestones (tentative max 3 classes, 2 weapons); first class promotion unlocks pets, mount unlock midgame. No prestige reset recommended.
Example: character level 30 Warrior with mastery 20 unlocks first promotion after trial; switches to Mage while retaining character level, gear and Warrior mastery. Mage starts with base skills and earns mastery more quickly through catch-up. Numbers illustrative only.

## Player-facing experience
Simple default view: character level, equipped class and mastery progress, next promotion requirement, one recommended next upgrade, current map objective. Smart equip and recommended skill builds are candidates, not mandatory auto-spend. Advanced detail can expose attributes, reaction tags, class synergy, damage statistics and summon odds without requiring them for ordinary advancement. Make gear/skill recommendations explainable and reversible; never automatically spend premium resources or disassemble locked items. Auto-combat should handle an ordinary viable build. Detailed UX/onboarding later.

## Open decisions
Character/class XP curves, whether mastery has a common cap or promotion-specific cap, distribution between equipped styles, offline class XP attribution, catch-up rates, exact promotion structure, player-assigned stats, unlock order for additional swap slots, character level caps, skill/talent relationship, promotion trial content. No numerical values or class progression implementation approved.
