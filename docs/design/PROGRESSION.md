# Character and class progression
2026-11-26 | Owner approved the overall progression model on 2026-11-26; exact implementation and numerical balance remain open.

## Established accessibility principle
The owner wants a cool, approachable experience for children and casual players, with optional depth for dedicated optimizers. Players need not understand all underlying systems to progress. Detailed onboarding and UX design deferred until systems are established. Favor automatic/default sensible choices, progressive disclosure, plain descriptions and recommendations; advanced build analysis is optional. Do not equate optional complexity with removing mechanical depth.

## Approved three-layer progression direction
1. Character Level (global XP): one permanent level for the character from combat, quests, stage clears, dungeons and eligible idle rewards. Represents general power, equipment eligibility and account/character system milestones. No reset on class switch. Automatic baseline attribute growth; optional deeper customization to be decided. Avoid hard-locking every stage behind level; dungeon completion remains main map gate.
2. Class Mastery (class XP): independent progression for each unlocked playable discipline, retained forever. Earn alongside Character XP by fighting, completing activities and eligible offline training. Class mastery unlocks ordinary skills/talents/benefits as appropriate and contributes to promotion eligibility. Proposed distribution: a designated training class receives full class XP; other equipped classes receive a smaller share if participating; alternatively split according to combat use. Do not require manual swaps or last hits to earn mastery, including supports. Exact shares undecided. New class starts with functional kit and inherits character level, equipment compatibility and general progression. Owner endorsed mastery catch-up. Recommended implementation: bonus for underdeveloped classes based on highest mastered class or character progress, tapering as they approach that benchmark, without instantly granting promotion; exact formula and eligibility open.
3. Promotions (milestones): climb each of the five proposed core lineages through earned mastery thresholds plus appropriate campaign milestones or short promotion trials. Promotions unlock distinct selectable combat styles/disciplines without replacing earlier ones, consistent with confirmed class expansion. Suggest a shared lineage eligibility record to avoid restarting a whole grind at each unlock; each individual promoted class still has mastery and distinct benefit. Special/hybrid classes unlock through specific accomplishments and possibly multi-class prerequisites, not necessarily a core lineage. Exact architecture (linear vs branches), names, level caps, promotion count, unlock requirements and inheritance still open.

## Supporting progression
Skill levels and star ranks remain separate from class mastery and use earned materials/duplicates. Gear, pets, mounts have own improvement tracks as already discussed. Avoid additional redundant weapon/account/ascension XP tracks unless a clear purpose is established. Character-wide progression unlocks additional class/weapon swap slots at milestones (tentative max 3 classes, 2 weapons); pets and mounts are available from the start; pet generations/variants become accessible through class progression plus high character level; mounts remain more universal. Potential pet ascension consumes another pet plus materials/currency. See SKILLS-AND-COLLECTION.md; exact gates and mechanics open. No prestige reset recommended.
Example: character level 30 Warrior with mastery 20 unlocks first promotion after trial; switches to Mage while retaining character level, gear and Warrior mastery. Mage starts with base skills and earns mastery more quickly through catch-up. Numbers illustrative only.

## Player-facing experience
Simple default view: character level, equipped class and mastery progress, next promotion requirement, one recommended next upgrade, current map objective. Smart equip and recommended skill builds are candidates, not mandatory auto-spend. Advanced detail can expose attributes, reaction tags, class synergy, damage statistics and summon odds without requiring them for ordinary advancement. Make gear/skill recommendations explainable and reversible; never automatically spend premium resources or disassemble locked items. Auto-combat should handle an ordinary viable build. Detailed UX/onboarding later.

## Open decisions
Character/class XP curves, whether mastery has a common cap or promotion-specific cap, distribution between equipped styles, offline class XP attribution, catch-up rates, exact promotion structure, player-assigned stats, unlock order for additional swap slots, character level caps, skill/talent relationship, promotion trial content. No numerical values or class progression implementation approved.


## Promotion requirement closure proposal (2026-11-26)
Recommend each core promotion requires appropriate class mastery threshold, a character/campaign milestone (already attained milestones count), and a class promotion trial/challenge designed for ordinary viable auto-combat with optional active input. No duplicate grind for already-cleared campaign gates, no summon rarity or paid requirement, no loss of character level or learned disciplines. Catch-up accelerates mastery but does not skip promotion eligibility or trial. Special/hybrid classes may require different accomplishments. Exact levels, trials, mastery caps and future branch structure deferred until class/content design. Overall progression direction already approved; these requirement rules await owner approval.

## Promotion refinement approved (2026-11-26)
Owner approves ordinary promotion requirements: appropriate Class Mastery, adventure milestone (already completed milestones count), and promotion trial achievable through ordinary automated combat with optional active input. Catch-up accelerates mastery, not automatic qualification. Prior classes and progression retained. Special/hybrid acquisition can differ. Exact thresholds and trial content deferred. Conceptual progression refinement complete.
