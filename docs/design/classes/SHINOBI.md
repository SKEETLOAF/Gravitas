Assassin -> Shinobi -> Blade Dancer is the established working sequence; ninjutsu, deception, afterimages and evasive counters are broad identity. ## Identity and profile
Anime-inspired martial ninja: hand seals, short-lived clones, substitution, thrown tools, martial combinations and elemental techniques. Assassin exploits existing vulnerability with precision; Shinobi creates opportunities with authored deception; Blade Dancer retains sustained broad combo identity; Summoner retains persistent autonomous units. No copyrighted character names, signature moves or assets copied; original visual language. Proposed Dagger primary, Gauntlet secondary (both existing families; Sword compatibility alternative remains open). Inherit compatible learned ordinary Assassin skills, not Exploit or exclusive passives. Sword-exclusive skills not silently converted. Health D(2), Energy B(4), ATK A(5), MATK C(3), DEF D(2), MDEF C(3) = 19. Proficiencies Evasion, Movement Speed, Effect Potency, Energy Efficiency. Physical martial/tool skills primarily ATK; explicitly magical elemental ninjutsu may use MATK or defined hybrid coefficients with ATK-majority where appropriate (candidate). No general dual-stat formula or new Chakra currency; Energy remains the paid resource. Keep physical-only and mixed builds viable.

## Trait — Art of Deception
- Completing a Core sequence while active creates one temporary Clone; a qualifying paid Clone Technique activation can also prepare one. Nonstacking, same-source refresh within cap; no creation from Clone actions, proc damage or inactive Core. Clone is a visible short-lived duplicate that can act as a partner, feint, decoy or technique assistant through authored actions, not persistent AI, targetable summon, separate inventory or independent skill loadout.
- Next explicitly Clone-compatible paid technique consumes the Clone once on activation, producing a skill-specific cooperative action: launching the Shinobi into a technique, preparing a seal, handing off a ninja tool, feinting or acting as a defensive decoy. Each interaction should be visibly distinct and mechanically purposeful. Not a full copy of a cast. No additional cooldown reset, resource refund, extra status budget or automatic critical. No arbitrary duplicate of inherited skill. Define compatible inherited skills explicitly if any.
- Clone action resolves promptly, with no separate targeting minigame or cinematic lock. If target dies, eligible area action may resolve at valid original location, no autonomous target pursuit or extra refunds. Short action cancellation and impact behavior TBD. Reuse animation/VFX pool, no independent pathfinding or physics. All damage attributed to Shinobi; secondary action cannot itself create/consume Clone, proc itself or multiply normal on-hit/reaction budget. Distinct visual and sound cue; simple automated rotations use the same rules.
- Substitution is a paid defensive technique, not universal free dodge: brief readiness against one eligible incoming ordinary attack targeted at Shinobi. Reduce a bounded part of resolved hit damage and relocate within valid zone if possible; stationary smoke/decoy fallback if not. No guaranteed evasion event, lethal prevention, threat reset, scripted mechanic immunity or movement through geometry. With Clone, improved protection or authored follow-up as specified. If no incoming hit, baseline short Evasion window remains useful; readiness expires normally. Clone is consumed on casting compatible technique; substitution-specific Clone effect is reserved for that cast until its expiry, cannot create second Clone. No automatic additional cooldown or shared resource.
- Active class Trait only; timer continues on swap, no new Clone while inactive; already committed actions may finish normally. Exact lifetime, coefficients, eligibility and stack order open. Core preparation makes co-op effective even if tank receives all incoming attacks.

## Selectable class passives (2)
- Phantom Arts: baseline Effect Potency; Clone-assisted offensive skills improve complementary impact/coverage within existing budget, not a second cast. For martial builds, eligible physical complementary strike benefits without requiring elemental status.
- Escape Artist: baseline Evasion; Clone-assisted defensive techniques gain stronger limited protection and shorter permitted movement recovery, including ordinary Substitution. No invulnerability or free repeated activation.

## Legendary Core skills (2)
- Silent Blade (guaranteed, either): swift martial sequence with a concentrated finisher; completing it creates Clone via Trait. First compatible technique after chain receives modest direct impact improvement. Dagger cuts/Gauntlet strikes reuse weapon-family animations.
- Sealbreaker (alternative, either): deliberate martial sequence ending in a short hand-seal gesture and neutral Energy-infused impact; completes Clone preparation and improves next eligible elemental technique application within cap. Neutral impact does not silently apply any element. Different cadence, not mandatory for ninjutsu; both Cores have normal baseline damage.

## Collectible passive skills (5)
- Paper Double: Substitution trades some mitigation for a short delayed neutral decoy impact on attacker, one eligible hit only; no full damage reflect.
- Scattersteel: Kunai Volley trades some first-target damage for more fan coverage and distinct-target hits, shared hit cap.
- Cinder Seal: Flame Breath trades some direct impact for longer residual Burn application, fixed application budget and no per-tick refresh.
- Hidden Step: Smoke Veil trades zone duration for a short movement/recovery benefit on leaving its footprint; no forced movement outside zone or evasion event from empty space.
- Twin Technique: Clone Technique trades some direct damage for a longer usable Clone lifetime within cap; if Clone already exists, modestly enhances next complementary action rather than adding second Clone. No self-trigger or repeated indefinite refresh.

## Example builds and automation
- Phantom striker: Silent Blade / Kunai Volley, Clone Technique, Phantom Formation / Phantom Arts / Warfare, Tempo. Either weapon.
- Ninjutsu: Sealbreaker / Flame Breath, Stormstep, Wind Cutter / Phantom Arts / Flow, candidate Influence if approved (otherwise Warfare). Both weapons; can trigger existing Fire+Lightning Overload or Fire+Resonance Wildfire only through actual valid application; no special reaction bypass.

- Mixed Dagger/Gauntlet with compatible inherited Assassin actives possible. Weapon slot assignment, inheritance and exact mixed scaling remain open. Auto generic executor prefers Core finishers before compatible skills without waiting indefinitely; no new manual input required. Preserve action/zone/recovery constraints.
