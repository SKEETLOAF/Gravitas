# Class architecture and design template
Updated 2026-11-26. Class expansion established; initial detailed planning scope is two promotions per foundation; ordinary P III evolutions also release in the P III content window (owner-confirmed), with names/identities deferred. Direct sequential core evolution topology confirmed; roster names and kits remain open.

## Established direction
- One persistent character per account (no alternate character saves planned at launch) can learn, independently develop and equip multiple distinct disciplines. Promotions unlock new disciplines without replacing prior classes or losing mastery. All earlier core disciplines remain accessible; core promotions unlock directly in sequence. Every class must have a distinct benefit, even relative to its ancestors.
- Classes have linked primary/secondary weapons; see [WEAPONS.md](WEAPONS.md). Shared weapons encourage synergy without requiring every compatible class pair to share a weapon (recommended).
- Hybrid classes may unlock through multiple developed disciplines, including advanced branches. Warrior + Cleric -> Paladin is an illustrative owner example, not a roster commitment. Warrior -> Berserker is an illustrative advancement.
- Independent special classes may be obtained via dungeons, events, battle passes or game passes; sources remain candidates. Earnable equivalent power and ordinary progression without payment remain guardrails.
- Character/class progression and promotion requirements are established in [PROGRESSION.md](PROGRESSION.md). Energy and shared combat rules are in [COMBAT-FOUNDATIONS.md](COMBAT-FOUNDATIONS.md).

### Soft attribute proficiencies
Owner accepts the foundational affinities as a working basis with Assassin's Movement Speed replaced by Effect Duration. Proficient soft attributes grow at roughly comparable, modest natural rates across classes; non-proficient soft attributes grow much more slowly. Approved normalized soft-attribute growth targets: 20 units of proficient natural growth or 5 units of non-proficient natural growth, against 75 units of external progression at a comparable benchmark. Proficient and non-proficient are alternative per-attribute rates, not additive contributions to the same stat. Equipment and talents are primary build-directed sources; pets and mounts supplement them, Style Score milestones offer modest collection-wide bonuses, and future relics may be build-defining. Equipment, pets, mounts, cosmetics, talents and other progression sources supply the bulk of soft-attribute growth. Proficiency is an affinity, not a restriction. ## Common class anatomy
- Class Mastery rewards: titles with small statistical bonuses (see ITEMIZATION.md), achievements/milestones, evolution eligibility, class-specific cosmetics, and existing Class Trait development. Mastery XP tracks each individual discipline separately from lineage XP. Ordinary class skills come from the base kit and skill summons, not Mastery milestone rewards. Promoted classes inherit learned compatible ancestral ordinary skills; no reverse inheritance or inheritance of class-exclusive Traits or selectable class passives. See PROGRESSION.md.
- Class Trait: exactly one inherent passive trait per class, unlocked and upgraded through Class Mastery and shared Ascension items. Not summoned or equipped in a selectable passive slot. Same-class specialization does not duplicate the trait. Class Trait is active only while its associated class is active; explicitly applied effects may finish their intended duration. Exact mastery thresholds, level caps, costs and effects open. Candidate identities (not approved kits): Warrior retaliation, Ranger precision, Mage spell sequencing, Assassin exploiting openings, Cleric divine favor.
- Basic attacks use universal weapon-family movesets/animations; skills use their own animations across all eligible classes. Class identity comes from skills, Traits, passives, talents and synergies rather than distinct basic animations per class.
- Confirmed skill architecture: Each class offers 2 Legendary Core Skills (basic attack choices; one guaranteed upon class acquisition), 4 Normal, 4 Rare and 2 Legendary ordinary active skills, and 5 passive skills. Each lineage additionally offers 4 shared starter Normal actives and 5 shared starter passive skills. Each class loadout equips 1 Core and 3 ordinary actives; proposed 5 passive-skill slots per class loadout, separate from the existing inherent Trait and two selectable class passives (one equipped per distinct class, both for specialization). Ultimates are deferred, not equipped now. Skill XP levels the slots rather than individual skills; individual stars and tiers remain skill-specific. Higher starting rarity provides a meaningful power advantage at comparable investment. Owner confirms max-star skill upgrades can tier up; exact star cap, tier ladder, costs and carryover open. Same-class specialization gets two Core/three-active loadouts, both existing class passives, one Trait; no cooldown reduction bonus. Identical skill cooldown sharing recommended. See SKILLS-AND-COLLECTION.md for canonical details.
- Ordinary active skills use shared Energy; individual cooldowns persist across swaps. Core basics recommended free. Ultimates deferred.
- Selectable class passives are distinct from inherent Class Traits and mastery talents. Each class offers two, normally equips one; same-class specialization unlocks both. Both equipped classes' selected passives remain available, but each passive must work with its associated equipped class and respect its class/action eligibility and trigger conditions. Do not automatically apply class-specific skill modifiers to another class; persistent effects may finish normally. Acquisition and upgrade rules open.
- Branching talents and saved talent loadouts are owner-approved. Owner approved five base trees shared across foundational lineages, with Go Go Muffin and Diablo-style inspiration.
- Each weapon has one dedicated skill that automatically draws its equipped weapon. Class skills may be universal across compatible weapons, weapon-specific or multi-family; inherited skills retain requirements. Exact timing and UI open. Basic attacks are weapon-family based.
- Two class selections and two shared weapons; shared gear/companions remain unchanged, class skills independently selected. Duplicate class selection grants scaling specialization and a second active-skill loadout, not a second Trait; no specialization cooldown reduction bonus. Class swap cooldown 0.5 seconds. Canonical rules in [COMBAT-SWITCHING.md](COMBAT-SWITCHING.md).

## Shared lineage talents (approved direction)
One reusable tree for each of five foundational lineages (Warrior, Ranger, Mage, Assassin, Cleric). All descendants access their lineage's tree; all classes may eventually access all five trees (owner direction). Working prerequisite: invest 40 points in a native tree before branching into another tree; hybrids have immediate access to both parent trees without this prerequisite. Ordinary classes unlock all other trees after investing 40 points in their native tree; normal native rank cost 1 TP, other trees 2 TP/rank. Hybrids have both parent trees immediately at normal 1 TP/rank; non-parent trees cost 3 TP/rank. Hybrid non-parent access requires 40 invested points across parent trees combined (owner-confirmed); exact respec behavior remains open. Extra point costs buy ordinary ranks, not additional effective ranks. Class-specific skill eligibility remains unchanged. Meanwhile, Class Traits, two selectable passives and individual skill kits provide class-specific identity. Each talent node has 3–5 investable ranks. Each rank adds a linear, explicitly defined effect increment; bonus effective ranks from items, future relics or specialization may exceed the normal investment cap and continue the same progression. Define a safe effect-level cap separately where needed for mechanics such as chances or cooldowns; never silently clamp effective rank to investment cap. No bonus-item or relic design approved by this rule. Individual effects are intentionally modest because invested talents accumulate and trees grow lengthy as more class evolutions are added (owner-approved). Balance total invested builds and cumulative combinations, not isolated nodes. Prefer small incremental attribute, conditional and transformative effects; occasional deeper defining effects are a candidate, not a required capstone system. Exact rank counts and magnitudes open. Base cost one point per rank in native/parent trees; ordinary cross-tree ranks cost two and hybrid non-parent ranks cost three (owner-confirmed). Recommend prerequisite ranks or branch-investment gates where useful rather than mandatory maxing of all preceding nodes. Three approved node categories: Attribute (increase existing attributes), Conditional (trigger benefits under combat conditions), and Transformative (modify compatible skill/mechanic behavior). Use reusable mechanical tags (Block, Break, healing, DoT, Energy, etc.) so nodes apply across promotions rather than requiring separate trees. Skill acquisition remains separate from talents through the established base-kit/progression/summon system. Do not add talent-exclusive skills by default. Exceptional unlocks, if ever needed, require separate review. Transformative modifiers may change elements, targeting, area or skill behavior; avoid duplicating skill-slot XP and individual star development. Trees may expand with future promotions, using permanent lineage milestones to unlock later sections; an unlocked descendant must not force a new tree or reset. Promotion-exclusive effects should generally live in its trait/skills/passives, not duplicate talent branches.
- Owner-approved source: earn exactly one talent point per level gained after the talent tree unlocks; initial hybrid tier-equivalent allotment is an explicit one-time acquisition exception, not a recurring reward. Each lineage earns and owns its own cumulative talent points through its level progression (owner-confirmed). Points remain owned by their earning lineage; recommend permitting that lineage's allocation to be spent in other unlocked trees without transferring or duplicating point balances. Exact cross-tree budget accounting remains open. Unlock level and treatment of the unlock-level gain remain open. Earned points are retained across Class Changes (owner-confirmed); recommend reusing capacity per saved allocation, never award a point merely for resetting to level 1; prevent repeat grants for the same earned level milestone. External bonus effective ranks remain distinct from earned talent points. Class Mastery and permanent lineage promotion milestones remain proposed access gates; no separate talent XP grind.
- Saved allocations/presets can be selected for different builds or individual classes within the same tree; reuse unlocked points/nodes without paying again. Respec and preset capacity open; no in-combat talent editing recommended.
- Talent contribution is slot-based rather than active-class-based: primary class allocation contributes full strength; secondary contributes weakened effective ranks, with a minimum of one effective rank for an invested node (interpretation of owner's minimum; verify). Uninvested nodes do not become active by default. Both contributions persist across class swaps, subject to node-specific conditions and compatible actions. Selecting the same class twice empowers the primary nodes instead of granting a second allocation; no duplicate Trait; the second active-skill loadout is independent of the single empowered talent allocation. Approved starting balance: secondary talent ranks scale at 50%, retaining fractional effective ranks internally with a minimum of one for each invested node; uninvested nodes stay at zero unless explicitly granted by a bonus. Same-class specialization uses 150% primary talent rank scaling, with no second allocation. Review low-rank breadth incentives during testing. Owner confirms overlapping talent nodes across distinct equipped classes in the same lineage stack by adding their effective ranks (primary full + secondary half, with existing minimum-one rule on invested secondary nodes). For example, ranks 5 and 5 yield effective rank 7.5; apply the node's linear effect once at its combined effective rank, subject to its defined effect-level limits. Same-class specialization remains a single 150% allocation. Ordering of external bonus ranks remains open; multipliers remain subject to balance testing. Use stable node IDs and linear per-rank effect formulas; preserve investment caps separately from effective ranks. Shared Health/Energy never replenish merely from swaps. The earlier active-allocation-only model is superseded.
- Hybrid/special talent access: owner confirms both parent trees are immediately available to a hybrid, with all five trees eventually accessible across classes. Hybrids are unique disciplines with their own independent level progression, mastery and earned talent point budget, analogous to special classes (owner direction). Do not average or sum parent talent budgets. Hybrid retains its own progression XP and additionally grants 50/50 parent-lineage progression (owner-confirmed: 50% each regardless of equipped slot; neither parent is primary or secondary). Parent overlap/deduplication details remain open. Owner confirms tier-equivalent starting talent points and subsequent normal TP earning; native/parent upgrades cost 1 TP/rank, retaining previously confirmed cross-tree multipliers. Proposed starter development: max the first two sections of both parent trees. ## Reusable class design template (proposal)
Use the same template for foundations, advanced, hybrid and special classes. Fill only established details; mark others TBD. Use the confirmed loadout capacities and universal Energy; unique mechanics are class-specific.

1. **Identity:** name, category, parent(s), fantasy, role(s), distinctive playstyle, status.
2. **Acquisition and progression:** prerequisites, unlock path, mastery, branch eligibility, progression retention, alternative paths.
3. **Class Trait:** one inherent upgradeable passive; define mastery and Ascension item requirements, level effects, activation scope, trade-offs and intended solo/co-op value. Do not assume permanent stacking.
4. **Weapons:** primary type, compatible alternatives, shared compatibility, weapon-specific interactions, proficiencies.
5. **Combat foundation:** attack chains, movement, offense, defense, range, resource/gauge if needed, signature loop.
6. **Kit:** one Trait, two selectable class passives, two Legendary Core choices (one guaranteed at acquisition), four Normal/four Rare/two Legendary ordinary actives, five passive skills; separate shared lineage starter pool. Equip one Core + three actives per class, proposed five passive-skill slots per loadout. Ultimates deferred. Define weapon compatibility, skill modifiers and cooldown ownership.
7. **Automation:** easy-to-author default macro/preset, reusable actions and class-specific sequence options, Impulse and swap opportunities, future manual compatibility.
8. **Synergies:** same-class kit, weapon overlaps, non-overlapping functional combos, swap-in/out effects, cross-class resources/buffs/cooldowns.
9. **Growth:** owner-requested inherent class attribute scaling with global Character Level; define a data-driven letter-graded class growth profile using the foundational 18-point Scaling Allotment plus one point per prestige, separately from Class Mastery, traits, gear and talents. Use approved class-slot growth multipliers; exact curves open. Shared lineage talent synergies, mastery milestones, advanced branches, new techniques, horizontal options; later hybrid prerequisites. Do not design a separate tree by default.
10. **Balance and experience:** strengths, weaknesses, solo viability, team contribution, farm/boss performance, comparisons, guardrails. Explicitly identify what makes this class distinct from parents, siblings and hybrids, and what reason remains to use its parent after unlocking it.
11. **Presentation and implementation:** silhouettes, animation, VFX/audio, UI indicators, required assets, dependencies, test cases.
12. **Decision record:** established, exploratory, future, undecided, discarded; next questions.
